DECORE HOMEZ — LUXURY INTERIORS WEBSITE DEMO

Open index.html in a browser. The site is responsive and includes a self-contained SVG fallback for every gallery image.

VISUALS
The demo uses selected free-to-use Unsplash photography as remote hero/gallery imagery, with local SVG fallbacks if an image cannot load. Before selling/publishing the final site, replace the demo photography with Decore Homez project photographs after receiving permission from the owner.
